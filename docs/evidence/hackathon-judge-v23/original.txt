VERIFIABLE WORKFLOW
Organizers escrow simulated StudioNet GEN and store a prose rulebook, scoring rubric, deadline and appeal window. Entrants publish a wallet/event/contract/repository/path challenge in a .txt file on the repository default branch. Each validator independently retrieves GitHub repository metadata, the default branch commit, and the file record. It verifies the Git blob digest and exact challenge, renders the commit-pinned raw file with gl.nondet.web.render(), and requires the rendering to match the authenticated file. Validators agree exactly on the capture and provenance record.

The immutable evidence package hashes the provenance record and snapshot digest, binding the wallet, event, contract, repository ID, commit, path, original summary digest and proof. A later jury independently evaluates the saved evidence against the prose rules. Exact eligibility and 20-point score bands must agree; confidence has a bounded tolerance; reasoning wording is exempt. One entrant appeal may supply a second verified package linked to the original package digest. Before prize settlement, the contract checks both packages again. The highest eligible score receives withdrawable prize credit and a wallet-based win credential. Unresolved judgments have a 24-hour permissionless inconclusive fallback.

SCOPE
This demonstrates repository publication control at capture. It does not attest legal ownership or originality, nor authenticate deployer claims about links mentioned in prose. The deployment signer has no privileged contract role. Demo entrants are controlled test wallets authorized to publish evidence in this repository. StudioNet GEN is simulated. The v2.3 site update follows successful live acceptance; the older video documents v2.2.
